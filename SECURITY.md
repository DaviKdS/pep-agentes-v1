# Segurança e Privacidade

## Permitido

- Scripts locais para reconstruir o pacote.
- Scripts para gerar documentação.
- Scripts para validar estrutura.
- Scripts para publicar no GitHub com comando explícito do usuário.

## Não permitido

- Coleta de dados pessoais sem consentimento.
- Exfiltração de credenciais, tokens, cookies ou chaves privadas.
- Remoção indevida de créditos ou licenças de terceiros.
- Código malicioso, evasivo, fraudulento ou invasivo.
- Ocultação de violações legais, acadêmicas ou contratuais.

## Boas práticas

- Usar `.env.example` como referência.
- Manter `.env` fora do Git.
- Revisar scripts antes de executar.
- Não publicar segredos.
- Não registrar dados sensíveis em logs.
